# 销售中心 6 模块 + 双向同步 · 操作说明书

## 1. 部署前准备

1. **执行迁移**（在 `backend/` 下）：
   ```bash
   alembic upgrade head
   ```
   目标版本 `d4e5f6a7b8c9`（销售中心 6 模块 + EBMS 同步 + M2.5/M2.6 核价折扣字段 + PAND-298 规则动作/参数迁移 + PAND-315 客户域字段与联系人关联表 + PAND-316 产品资料/标准报价表、样品字段与状态迁移）。
2. **初始化编号序列**：样品（`SMP`）与反馈（`FB`）编号已注册，首次生成会自动建序列；历史数据导入后建议执行 `ensure_sequence_floors()` 对齐计数器下限。
3. **配置 EBMS 入站令牌**（环境变量 `.env`，生产必填）：
   ```
   EBMS_INBOUND_TOKEN=<强随机令牌>
   ```
   ⚠️ **未配置令牌时入站端点返回 503，系统拒绝服务**——这是有意设计（生产禁止默认口令），不是故障。
4. **权限发放**：6 模块权限点已并入 `admin / boss / manager / sales` 角色模板；如需精细控制，在「系统设置 → 角色」中按人勾选（订单/样品/报价库/反馈 四组权限点）。

## 2. 各模块操作

### 2.1 客户（/customers）
- 新增字段（对齐 EBMS 表单）：曾用名、母公司编码、销售模式（外销/内销/外贸公司）、客户状态、决策人及职位、决策核心需求、最近成交年份、开票抬头、税号、开户行、账号、国家地区。
- 客户等级为四分类字典（A级核心大客户 … D级新客/休眠客），等级长度已放宽至 30 字符。
- **查重（16-15）**：列表页「去重合并」按钮会展示系统检测结果——名称精确相同（忽略首尾空格与大小写）为确定重复；税号相同或联系人电话/手机相同为「疑似重复」。疑似不代表自动合并，须人工在弹窗中选择「保留的主客户」与「合并掉的客户」并确认（需 `customer:merge` 权限）。无重复时弹窗显示「未检测到重复客户」。
- **导入去重（16-15）**：Excel 导入按「客户名称 + 税号」去重。名称已存在→该行跳过，原因为「客户名称已存在」；税号已存在→跳过，原因为「税号已存在（疑似重复）」。导入结果逐行返回 `imported / skipped / reason`。

### 2.2 询价（/inquiries）
- 询价状态对齐 EBMS 11 态；旧 6 态自动映射（DRAFT→new、SUBMITTED→config_generated 等）。
- 询价条目新增：内部型号、证书合规（是/否）、证书等级（国标/行标/企标/无证书）、报价有效期。

### 2.3 报价库（/quote-library）
- 业务键 = 外部型号 + 证书等级（CE/ROHS/CCC/UL/ETL），同键不可重复。
- 新建时价格 RMB/USD 至少填一项；证书等级非法会被 409 拒绝。
- 顶部统计卡展示按证书等级、按类目的数量分布。

### 2.4 订单管理（/orders）
- 订单行以「订单号 + 行号」唯一；可筛选订单号/客户/产品/项目号/状态/风险。
- 状态流转按正向链推进（open→confirmed→…→shipped→completed），`closed`/`cancelled` 需显式选择，终态不可再转；跳级会被 409 拒绝。
- 风险等级双轨：表单录入 low/medium/high，列表过滤 blue/yellow/red。
- 被入站锁定的订单（`user_status_locked`）状态不会被 EBMS 事件覆盖。
- **入站状态同名映射（16-09）**：EBMS 订单事件中的 `completed` / `closed` 按同名写入 CRM（`completed→completed`、`closed→closed`）；未声明状态按原值透传，不改变订单状态机与终态规则。

### 2.5 样品管理（/samples）
- 样品号自动生成 `SMP-0001` 起，全局递增；也可手工指定。
- **5 态进度**：待确认 → 制作中 → 测试中 → 已寄出 → 客户反馈；列表状态列带进度条，只能逐级前进，跳级/回退/终态继续流转会被拒绝并提示下一状态。
- 必填/常用字段：**产品型号（必填）**、数量（>0，最多 2 位小数）、样品要求、**负责人**（默认创建人）、**计划完成日期**（默认创建日 +7 天，不得早于创建日）、样品类型（常规/新品/改良/急样）、关联询价号、客户名称、备注。
- **流转到「已寄出」**必须填写快递公司、快递单号、寄出日期；**流转到「客户反馈」**必须填写客户反馈与反馈日期。快递单号 6–40 位字母/数字/连字符且全局唯一，重复时提示「快递单号：已被样品 SMP-xxxx 使用」。
- 筛选：关键词（样品号/客户/产品型号/产品名称/询价号）、状态、负责人、计划完成日期区间、仅看逾期；计划完成日期已过且未到终态的样品显示「逾期 N 天」，统计卡同步显示逾期总数。

### 2.6 问题反馈（/feedback）
- 反馈号自动生成 `FB{YYYYMMDD}{seq}`；类型（bug/feature/improvement/question）、优先级（low/medium/high/urgent）。
- 详情抽屉内以时间线展示跟进（提交/评论/状态/指派/解决），支持追加评论、指派处理人、状态流转（open→processing→resolved→closed，线性）。
- 删除反馈会级联删除其跟进记录。

### 2.7 核价与报价（折扣审批，/pricing 与 /quotations）

- 新建核价时录入 9 项成本（材料/人工/包装/运费/模具/定制/起订量/其他/损耗，损耗默认 0）+ 目标利润率（默认 0.2）+ 折扣率（默认 1）。
- 报价公式（自动计算，无需手工填价）：`最终价 = 总成本 × (1 + 利润率) × 折扣率`；`底价 = 单位成本`（零利润底线）。成本/中间值 4 位、对外报价 2 位。
- 折扣审批三档（提交核价/报价时自动判定）：
  - 折扣率 = 1：**免审**，直接放行；
  - 折扣率 [0.95, 1)：**经理**审批（角色 `manager`）；
  - 折扣率 < 0.95：**总监**审批（角色 `boss`）。
- **金额门槛（可选，默认关闭）**：由 `system_config` 的 `approval.discount_amount_threshold_enabled`（`false`/`true`）与 `approval.discount_amount_threshold`（默认 `50000`）控制。关闭时完全按上面三档判定；开启后金额严格大于门槛自动升一级（免审→经理、经理→总监；总监已是最高档）。
- 未批行为：核价/报价未审批通过时，**不能生成/导出报价单 PDF/Excel**，只能保存核价草稿；折扣率须 ∈(0,1]（≤1）。
- 由核价生成报价或新建报价时，汇率从 `system_config` 的 `pricing.exchange_rate` 取值快照（默认 7.25，人工维护）；新建报价显式传入 `exchange_rate` 时以传入值为准。
- 参数维护（管理员）：直接更新 `system_config` 表，如 `UPDATE system_config SET value='7.35' WHERE key='pricing.exchange_rate';`。修改只影响之后创建的报价，已快照的报价不变。
- **导出取整（M2.5-D4）**：报价单 PDF 与 Excel 的单位价一律 2 位（例：`final_price=148.20`、数量 7 → 单位价 `21.17`）；PDF 金额/合计为 2 位并保持「金额 = 单价 × 数量」对账，Excel 单位价设为 `0.00` 数字格式，不再出现 4 位对外价。

### 2.8 交付逾期判定（订单异常上报，16-06）

- 判定以订单「承诺交期」为主：承诺交期早于判定日当天即视为逾期，逾期天数 = 判定日 − 承诺交期（最小 1 天）。**有承诺交期时，SLA 天数不参与判定。**
- 仅当订单未填写承诺交期时，才使用兜底规则：业务时间（订单创建时间）+ SLA 天数早于判定日即逾期；`sla_days` 默认 7 天。
- 判定范围为未发货的推进态订单（`open / confirmed / procurement_ready / material_ready / packaging_done`）；已发货（`shipped`）及终态（`completed / closed / cancelled`）不参与。
- 严重度按逾期天数：≥30 天 `critical`、≥14 天 `high`、≥7 天 `medium`、<7 天 `low`。
- 操作：调用 `POST /api/v1/integrations/ebms/pilot-b/exception`（需 `integration:view` 权限），可传 `sla_days`（默认 7）、`as_of`（判定时点）、`limit`；`deliver=true` 时入队后立即投递 EBMS。返回 `total / created / skipped` 及逐单 `days_overdue / basis`——`basis=promised_date` 表示按承诺交期判定，`basis=sla` 表示无交期兜底。
- 建议先以 `deliver=false` 试跑核对逾期清单，确认无误后再 `deliver=true` 正式上报。

### 2.9 线索、客户建档与联系人（/leads、/customers、/contacts）

**线索（PAND-315）**

- 新建线索时填写：公司/联系人/邮箱/电话/国家/行业、**具体需求内容**、**线索等级**（A 高意向 / B 中意向 / C 低意向，默认 B）、**初步背景调查**、**客户渠道分类**（展会 / B2B 平台 / 官网询盘 / 客户推荐 / 自主开发 / 代理商 / 社媒 / 其他）。
- 保存前系统自动查重（线索、客户、联系人三表）：名称/邮箱/电话完全相同为**确定重复**；邮箱域相同（非免费邮箱）、去除 Ltd/LLC/有限公司 等后缀后名称相同、公司名或官网命中邮箱域为**疑似重复**。
- 命中重复时弹出候选清单（最多 20 条，含负责人/联系方式/最近跟进）：
  - 确定重复：默认不能继续新建；如业务确认仍需新建，勾选「仍然创建」并填写查重说明（会追加到线索/客户备注）。
  - 疑似重复：填写「非重复说明」（1~200 字）后可继续。
- **转化为客户**：点击「转化」后选择「关联到已有客户」（从候选客户中选择，系统不再新建公司）或「新建客户」；可设置联系人关系类型。疑似重复同样需填写非重复说明。新建客户会自动带入来源、公司背景与「由线索 XX 转化」备注。
- 线索列表显示**负责人、最近跟进、下次跟进日期**，支持按状态、等级、渠道、负责人、是否逾期筛选。

**客户建档（PAND-315）**

- 新建/编辑客户可维护：来源、客户类型（终端用户/贸易商/代理商/分销商/生产工厂/其他）、负责人、付款方式（T/T、L/C、D/P、D/A、O/A、西联、现金、其他）、公司背景、主营产品、品牌、销售渠道及市场、官网（须以 http:// 或 https:// 开头）、地址。
- 客户列表顶部 Tab 按**新客户 / 活跃客户 / 休眠客户**分组并显示数量：
  - 新客户：建档 ≤90 天且尚无已完成/已关闭订单；
  - 休眠客户：非新客户，且客户状态为「未合作休眠客户」，或最近跟进超过 180 天，或无跟进且建档超过 180 天；
  - 活跃客户：其余客户。
  - 分组为系统自动判定，鼠标悬停分组标签可查看判定原因；导入/修改跟进记录后分组会自动变化。
- 列表支持按来源、类型、付款方式筛选，并显示主要联系人及联系方式。

**联系人（PAND-315）**

- 在客户详情「联系人」Tab 内可直接**添加联系人**、查看关系类型/微信/WhatsApp、**设为主要联系人**或**解除关联**（解除关联不删除联系人主档）。
- 同一联系人可关联多个客户，关联建立时可选择关系类型（决策人/采购/技术/财务/物流/其他）；每个客户至多一个「主要联系人」，用于客户列表展示。
- 新建联系人时若邮箱、电话/手机或微信与已有联系人相同，系统提示「检测到已有相同联系人」，可选择：
  - **关联到已有联系人**：把既有联系人关联到当前客户，不重复建档；
  - **仍然新建独立联系人**：适用于同名同号但确属不同个人的情况。
- 联系人列表展示关联客户（多客户时显示 `+N`）、关系类型、微信与 WhatsApp；按客户筛选时同时命中新关联表与旧所属客户字段。
- 权限：新建联系人需 `contact:create`，关联/设为主要/解除关联需 `contact:update`；客户档案字段与分组为只读展示，修改客户资料需 `customer:update`。

### 2.10 产品资料与标准报价（/products →「产品资料」）

**产品资料**

- 在产品列表点击「产品资料」打开抽屉，按 5 类资料分 Tab：销售资料 / 规格书 / 测试报告 / 认证文件 / 标准报价。
- 上传：选择文件 + 填写版本号（同类型内唯一，留空自动递增 `v1`、`v2`…）。单个文件不超过 **50 MB**，仅支持 pdf/doc/docx/xls/xlsx/ppt/pptx/png/jpg/jpeg/zip。
- 每个类型仅一条「当前版本」，其余为历史版本；可改版本号、下载、删除（软删）。删除/改版本后系统自动重算当前版本。
- **标准报价**：按币种（USD/CNY/EUR/JPY/GBP）与数量区间维护单价，数量区间为 `[起, 止)`，止留空表示无上限；有效期起止日期必填，版本号同币种内唯一。
- 报价状态自动派生：生效中 / 未生效（未到生效日）/ 已过期 / 已停用；停用后不再参与选价与重叠校验。
- 「按数量选价」输入数量即可取出该数量命中、生效中的最高版本报价；无命中时提示「无适用的标准报价」。

### 2.11 商机流转（/opportunities →「阶段流转」）

- 点开商机详情 →「阶段流转」，系统列出所有可去往的目标阶段；选中目标阶段后会先做**必填信息预检**：
  - 标签为绿色「已满足」的字段已自动从来源单据（询价单、核价单、样品单等）带出；
  - 红色「待填写」需在弹窗表单补齐，未补齐时「确定」按钮不可提交；
  - 若显示「仅限【销售经理、销售总监】操作」，说明当前账号角色不够，可请主管代办。
- 提交失败时会给出明确中文原因，如「流转至【报价】失败：缺少必填项——报价金额、数量」「不能从【询价】直接流转到【成交】」「未找到可自动带出的来源单据」。
- 询价、核价、报价单等单据新建/更新后，商机可能自动前移阶段（只前进不后退），无需手工重复流转。

## 3. 双向同步操作

### 3.1 出站（CRM → EBMS）
- 上述任一模块的新增/编辑/删除会自动生成 `AEOS.Event.V1` 事件进入 Outbox 队列投递，无需手工操作。
- 红线：**CRM 侧从不直写 EBMS 库**，仅经契约通道投递；投递失败按 `EBMS_MAX_RETRY`（默认 5 次）重试。

### 3.2 入站（EBMS → CRM）
- EBMS 调用 `POST /api/v1/integrations/ebms/ingest`（或 `/ingest/batch`），请求头 `Authorization: Bearer <EBMS_INBOUND_TOKEN>`。
- 幂等：幂等键以「整包指纹（剔除 `occurred_at`/`event_id`/`trace_id`/`idempotency_key`）」生成，同一事件重复投递直接返回 `duplicate`，不会重复写入。
- 冲突规则：对象已存在时仅应用 `external_id`（EBMS 拥有字段），其余字段改写被记为 OWNER_KEPT 冲突（不改本地）；订单锁定（LOCKED，仅跳过 `status`、其余字段照常按 Owner 规则同步）、迟到事件（STALE）、未同步出站时删除（DELETE 保护）分别留痕/拒绝。
- **订单状态同名映射（16-09）**：入站订单事件的 `completed` / `closed` 按同名写入（`completed→completed`、`closed→closed`）；未声明状态原值透传，不会映射成其他 CRM 状态。

### 3.3 对账与冲突裁决
- 查看冲突：`GET /api/v1/integrations/ebms/conflicts`（需 `integration:view` 权限），按对象类型筛选。
- 每条冲突记录入站值（incoming_value）与本地值（local_value）对照，供人工裁决；裁决后如需以 EBMS 为准，请由人工在 CRM 侧修改后再触发同步。

## 4. 运维要点

| 事项 | 说明 |
|---|---|
| 入站令牌 | 生产强随机；泄露立即轮换并重启服务 |
| 编号并发 | Redis INCR 优先，Redis 不可用自动回退数据库行锁，保证不重号 |
| 迁移回滚 | `alembic downgrade -1` 可整包回滚（含 7 张新表与加列；PAND-316 迁移会同步删除产品资料/标准报价表并回退样品字段） |
| 同步状态 | `PENDING/SYNCING/SYNCED/CONFLICT` 记录在各实体 `sync_status/last_sync_at` |
| 契约版本 | 事件信封统一 `AEOS.Event.V1`；EBMS 补全 schema 后只需收敛取值域常量，无需改模型 |

## 5. 常见问题（FAQ）

- **入站返回 503**：`EBMS_INBOUND_TOKEN` 未配置，属预期保护，请配置令牌。
- **入站返回 422**：事件契约字段缺失/取值越界；批量场景会在写入前整体校验，避免半截写入。
- **订单状态流转被拒（409）**：目标不在 `allowed_order_transitions`（正向链），或订单被入站锁定。
- **报价库新建被拒（409）**：证书等级非法，或「外部型号+证书等级」已存在，或 RMB/USD 价格均未填。
- **编号重复**：执行 `ensure_sequence_floors()` 将计数器与库内最大编号对齐。
- **逾期清单为空/漏单**：确认订单是否处于未发货推进态、是否已填承诺交期；无交期订单按 `sla_days`（默认 7 天）兜底，可调整入参后重试。
- **导入客户被判重复**：名称相同或税号相同会被跳过；如确需导入，请先人工合并/修改原客户（或核对税号）后再导入。
- **新建/转化线索被提示重复（409）**：确定重复（名称/邮箱/电话完全相同）需确认后勾选「仍然创建」并填写查重说明；疑似重复填写「非重复说明」即可继续。转化时也可选择「关联到已有客户」。
- **新建联系人提示「已有相同联系人」**：按邮箱/电话/手机/微信判定同人；选择「关联到已有联系人」可复用主档，选择「仍然新建独立联系人」则新建独立记录。
- **客户分组与预期不符**：分组按建档时间、最近跟进（公司维度的活动记录）与订单完成情况实时计算；补充跟进记录或订单状态变化后刷新即可。悬停分组标签查看具体原因。
- **上传产品资料失败**：确认文件类型在白名单内且不超过 50 MB；同一资料类型下版本号不能重复。
- **按数量选价提示「无适用的标准报价」**：检查报价是否生效（未过期、未停用）、数量是否落在区间 `[起, 止)` 内，以及该币种是否已有报价。
- **商机流转按钮点不了/提交报缺项**：以弹窗内预检标签为准，补齐红色「待填写」字段；提示角色不足时需由对应角色操作。
- **样品流转被拒**：样品只能按 待确认→制作中→测试中→已寄出→客户反馈 逐级前进；「已寄出」需快递公司与单号，「客户反馈」需反馈内容与日期。
- **快递单号重复**：同一单号只能绑定一个未删除样品，请核对历史样品或更换单号。
- **联系人解除关联后客户列表无主要联系人**：解除后系统会自动顺延该客户剩余联系人中的一个为主要联系人；如已无联系人，则显示为空。
